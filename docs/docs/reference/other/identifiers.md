## Description
Identifiers are the names you give to **symbols**, **collections**, **sheets**, or _fields_. All identifiers are case-insensitive (this means that Gramble treats _nouns_ as the same as _Nouns_ or _NOUNS_). There are a small set of characters that cannot be used in identifiers including: `>`, `<`, `%`, `(`, `)`, `/` (the slash operator), ` ` (space), `.` (this is used for intersheet and collection reference).

A valid identifier must begin with either a letter, mark (any Unicode combining mark/diacritic/accent), a modifier symbol (accents and diacritics, modifier arrows and marks, or spacing signs), or `_` (underscore). The subsequent characters may be drawn from the set of valid first characters, or be a number, `_`, `@`, `#`, `$`, `-`, `'`, or `"`.
